
# Project 1 : Budgeting App

The Interactive Budgeting/Expenses App is a user-friendly web application designed to help individuals and families manage their finances effectively. Built using React and React Router DOM, this app provides a dynamic and responsive interface for tracking income, expenses, and budgeting goals. Users can gain insights into their spending habits, set financial goals, and make informed decisions about their finances.
